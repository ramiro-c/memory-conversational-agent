# memory-conversational-agent

Agente conversacional con memoria de corto plazo (buffer) y
largo plazo (recall vectorial), compresión de contexto,
scoring de relevancia y sync entre sesiones.

**Qué demuestra:** memoria útil sin saturar el contexto del LLM.

## Checklist de features clave

- [ ] Buffer de memoria a corto plazo
- [ ] Recall vectorial de memoria a largo plazo
- [ ] Compresión de contexto cuando crece el historial
- [ ] Scoring de relevancia al recuperar recuerdos
- [ ] Sincronización de memoria entre sesiones
